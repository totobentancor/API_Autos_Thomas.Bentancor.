Sistema de Automóviles

Aplicación para administrar un listado de automóviles mediante una API REST.

Inicio Consultar Agregar Modificar Eliminar

Administración de vehículos

Desde el menú de arriba se puede:

  • Consultar: ver todos los autos, o buscar uno por su ID.
  • Agregar: cargar un auto nuevo.
  • Modificar: buscar un auto por ID y cambiar sus datos.
  • Eliminar: buscar un auto por ID y borrarlo.
